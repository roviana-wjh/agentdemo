# 意图识别测试文档

## 📋 测试目标

验证统一对话流（UnifiedChatFlow）的意图识别准确性，确保系统能够正确区分**知识问答（RAG）**和**工具调用（BlogTool）**两种场景。

---

## 🗂️ 测试数据集

### 数据集结构

- **总测试用例**: 33个
- **分类维度**: 6个测试类别
- **意图分布**: 
  - `blog_tool`: 14个用例 (42%)
  - `knowledge_rag`: 19个用例 (58%)

### 测试类别

#### 1. 关键词匹配 - 工具调用 (7个)
验证Layer 1关键词快速匹配对工具调用类问题的识别能力。
- 预期置信度: >0.9
- 示例: "最近有哪些热门文章？"

#### 2. 关键词匹配 - 知识问答 (6个)
验证Layer 1关键词快速匹配对知识问答类问题的识别能力。
- 预期置信度: >0.9
- 示例: "什么是RESTful API？"

#### 3. LLM分类 - 语义理解 (6个)
验证Layer 2 LLM语义分类能力，处理无明显关键词的复杂问题。
- 预期置信度: 0.8-0.9
- 示例: "给我推荐一些值得看的内容"

#### 4. 边界情况 - 模糊查询 (4个)
验证Layer 3 Fallback机制，处理极度模糊的问题。
- 预期置信度: 0.3-0.8
- 示例: "告诉我更多"

#### 5. 混合场景 (3个)
验证对包含多重意图的复合问题的处理。
- 预期: 识别第一个/主要意图
- 示例: "最热门的Vue文章有哪些，以及Vue的核心原理是什么"

#### 6. 上下文依赖 (3个)
验证依赖历史上下文的问题的Fallback行为。
- 预期: 通常fallback到RAG
- 示例: "它是怎么工作的？"

## 📊 评估指标

### 主要指标

1. **准确率 (Accuracy)**
   - 目标: ≥85%
   - 计算: 正确分类的样本数 / 总样本数

2. **平均响应时间**
   - 目标: <300ms
   - 包含意图识别时间

3. **置信度分布**
   - Layer 1 (关键词): >0.9
   - Layer 2 (LLM): 0.8-0.9
   - Layer 3 (Fallback): 0.3

### 混淆矩阵

```
                  预测
               RAG    Tool
实际  RAG      TP     FP
      Tool     FN     TN
```

### 分层准确率

- **Layer 1准确率**: 关键词匹配的成功率
- **Layer 2准确率**: LLM分类的成功率
- **Layer 3使用率**: Fallback触发的频率

## 🔍 报告分析

测试完成后会生成 `test/intent_test_report.json`，包含：

```json
{
  "timestamp": "2026-09-08T15:30:00Z",
  "summary": {
    "total_cases": 33,
    "passed": 29,
    "failed": 4,
    "accuracy": 87.9,
    "avg_response_time": 178,
    "failed_by_intent": {
      "blog_tool": 2,
      "knowledge_rag": 2
    },
    "failed_by_method": {
      "keyword_match": 0,
      "llm_classification": 3,
      "fallback_default_safe": 1
    }
  },
  "details": [...]

```

### 关键分析点

1. **accuracy** - 整体准确率
2. **failed_by_intent** - 哪种意图更容易识别错误
3. **failed_by_method** - 哪层识别方法失败最多
4. **avg_response_time** - 性能是否满足要求

## 🐛 故障排查

### 常见问题

1. **服务未启动**
```
❌ 加载测试数据集失败: connection refused
```
解决: 确保go-agent服务已启动

2. **未找到route事件**
```
⚠️  失败原因: 未找到route事件

```

